## ADDED Requirements

### Requirement: 设计令牌与权威值一致

前端共享样式 `assets/styles.css` 的 `:root` 设计令牌必须与 `21` §3.3（=`24` §3.1 原样内联）逐一一致。12 个色令牌（`--bg` / `--panel` / `--ink` / `--muted` / `--line` / `--blue` / `--blue-soft` / `--amber` / `--amber-soft` / `--green` / `--red` / `--grid`）的色值以 `21` §3.3 为单一事实来源，禁止硬编码冲突色值（`24` §6.3）。冷路径 L2 问句 chip 描边用紫灰 `#5b4b96`（`24` §6.3）。

#### Scenario: 12 个色令牌值对齐 21 §3.3
- **GIVEN** `assets/styles.css` 的 `:root` 块
- **WHEN** 逐一比对 12 个色令牌的取值
- **THEN** 每个令牌的色值与 `21` §3.3（=`24` §3.1）完全一致

#### Scenario: 派生冲突色不残留
- **GIVEN** `assets/styles.css` 中使用派生色的组件（`.pill.ok` 背景、`.btab` 表头背景、`.dock` 阴影）
- **WHEN** 检查其色值
- **THEN** 分别对齐 `21` §3.4 极浅绿 `#e6f6ec`、`21` §7.6 表头蓝浅底 `#f3f8ff`、主色蓝 `--blue` 的派生阴影

#### Scenario: L2 冷路径 chip 描边为紫灰
- **GIVEN** 对话台 L2 问句 chip `.qs.l2`
- **WHEN** 检查其描边色
- **THEN** 描边为 `#5b4b96`（`24` §6.3），非其它紫色

### Requirement: 角色菜单可见性（前端过滤）

登录后按当前角色过滤左侧导航菜单项，可见集与 `13` §3.1 矩阵一致：仓管员 7 / 计划员 4 / 主管 6 / 管理员 8。角色取值严格为 `warehouse_keeper` / `planner` / `supervisor` / `admin`（`13` §一）。过滤只作用于导航渲染（隐藏菜单项与空组标签），不取代后端 RBAC（路线图，`13` §六）、不拦截直接 URL 访问。

#### Scenario: 四角色菜单可见集与矩阵一致
- **GIVEN** 四个角色逐一登录
- **WHEN** 渲染左侧导航
- **THEN** 可见菜单项数分别为 仓管员 7 / 计划员 4 / 主管 6 / 管理员 8，且可见集与 `13` §3.1 逐行一致（配置页仅管理员全开、主管可见、仓管员/计划员不可见；数据导入页主管不可见；入库页仅仓管员/管理员）

#### Scenario: 空组标签随过滤收起
- **GIVEN** 某角色（如计划员）的「三类作业」组下所有菜单项均被隐藏
- **WHEN** 渲染导航
- **THEN** 该组标签（`.grp`）一并隐藏，不出现孤立组标签

#### Scenario: 未登录不过滤
- **GIVEN** 会话中无角色（未登录态，如登录页）
- **WHEN** 渲染导航
- **THEN** 显示全部 8 项（原型总览，不套用矩阵）

### Requirement: 四态占位系统化

全局提供 空 / 加载 / 成功 / 异常 四态占位样式与触发钩子（`21` §7.11）：空态引导文字、加载态转圈/骨架、成功态绿字说明、异常态红字 + 重试/返回。四态口径权威来源为 `11` §五 与 `22` 各页状态表。

#### Scenario: 四态 class 齐备且不冲突
- **GIVEN** `assets/styles.css`
- **WHEN** 检查四态占位 class 与触发钩子
- **THEN** 空/加载/成功/异常 四态样式齐全，加载态含转圈（`.spin`），且与既有 `.hidden` / `.login-err` 语义不冲突

### Requirement: 流程状态卡 .node 三态

流程状态卡 `.node` 提供 entry（蓝·入队）/ exec（绿·执行）/ ledger（琥珀·写台账）三态，配合 `.flow` 管线容器串起「入队 → 执行 → 写台账」作业管线可视化（`21` §7.2 / §7.8，`15` 状态机）。

#### Scenario: .node 三态配色对齐 21
- **GIVEN** `assets/styles.css` 的 `.node` 组件
- **WHEN** 检查三态样式
- **THEN** `entry` 蓝（`--blue`）、`exec` 绿（`--green`）、`ledger` 琥珀（`--amber`），与 `21` §7.2 / §7.8 一致
